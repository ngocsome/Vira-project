# 1. Context

**Problem:**
Người dùng sau khi đăng ký trước đây bị rơi vào các màn hình rời rạc và bị "khóa" trong một dự án duy nhất. Khi đang ở trong ứng dụng chính (App Shell), không có cách nào để tạo thêm dự án mới, tạo thêm workspace mới, hoặc chuyển đổi qua lại giữa các dự án / workspace giống như trải nghiệm chuẩn của Jira.

**Affected Modules:**
- `src/main.jsx` — Quản lý state app, tích hợp Onboarding Wizard `<Setup>`, bổ sung component `<WorkspaceSwitcher>`, `<CreateProjectModal>`, `<CreateWorkspaceModal>`.
- `src/styles.css` — Định dạng giao diện dropdown switcher, danh sách item, hover, active badge và modal form.

**Non-Goals:**
- Không thay đổi schema cơ sở dữ liệu backend (backend đã có sẵn toàn bộ API cho workspace và project).
- Không can thiệp các trang chức năng bên trong dự án (Board, Backlog, Sprint, Members).

---

# 2. Constraints

**Language / Tech:** React 19, Vanilla CSS, Lucide icons, Vite SPA.  
**Rules:**
- Tái sử dụng các lớp CSS modal chuẩn (`.modal-layer`, `.task-modal.form-modal`).
- Duy trì tính phản hồi tức thì (optimistic / instant state update khi chuyển đổi dự án).
- Tự động đóng dropdown switcher khi click ra ngoài (`mousedown` listener).

---

# 3. Conventions

**Naming:**
- Components: `PascalCase` (`WorkspaceSwitcher`, `CreateProjectModal`, `CreateWorkspaceModal`).
- Handlers: `camelCase` (`handleSelectProject`, `handleCreateWorkspace`).
**Error Handling:**
- Bắt lỗi API và hiển thị thân thiện qua `errorText(err)`.
**Validation:**
- Project Key: regex `[A-Za-z][A-Za-z0-9]{1,11}`, tự động viết hoa và tự động trích xuất gợi ý từ Tên dự án.

# 4. Contracts

## Component: `<CreateProjectModal>`
```typescript
interface CreateProjectModalProps {
  token: string;
  workspaceId: number;
  onCreated: (project: ProjectResponse) => void;
  onClose: () => void;
}
```
- **Pre-condition:** `workspaceId` hợp lệ, `token` còn hiệu lực.
- **Post-condition:** Gọi `viraApi.createProject`, nhận về `ProjectResponse`, gọi `onCreated(project)` và `onClose()`.

## Component: `<CreateWorkspaceModal>`
```typescript
interface CreateWorkspaceModalProps {
  token: string;
  onCreated: (workspace: WorkspaceResponse) => void;
  onClose: () => void;
}
```
- **Pre-condition:** `name` không được rỗng.
- **Post-condition:** Gọi `viraApi.createWorkspace`, nhận về `WorkspaceResponse`, gọi `onCreated(workspace)` và `onClose()`.

## Component: `<WorkspaceSwitcher>`
```typescript
interface WorkspaceSwitcherProps {
  token: string;
  currentWorkspace: Workspace;
  currentProject: Project;
  onSelectProject: (project: Project) => void;
  onSelectWorkspace: (workspace: Workspace) => void;
  onOpenCreateProject: () => void;
  onOpenCreateWorkspace: () => void;
}
```
- **Pre-condition:** Render tại vị trí `div.workspace` trong sidebar.
- **Post-condition:** Hiển thị dropdown với 2 nhóm: Dự án của workspace hiện tại và Danh sách tất cả workspace.

# 5. Target Architecture & Interaction Flow

```
[Sidebar Widget: div.workspace (Click)]
               │
               ▼
   [Toggle WorkspaceSwitcher Menu]
         ├── Click Project Item ──────────> onSelectProject(project) (Instant Switch)
         ├── Click "+ Tạo dự án mới" ────> Open <CreateProjectModal> ──> onCreated ──> Switch to New Project
         ├── Click Workspace Item ────────> onSelectWorkspace(workspace) (Switch Workspace)
         └── Click "+ Tạo workspace mới" ─> Open <CreateWorkspaceModal> ──> onCreated ──> Switch to New Workspace
```

# 8. Task Specifications

### Task 1: Xây dựng `<CreateProjectModal>` và `<CreateWorkspaceModal>`
- **Files:** `src/main.jsx`, `src/styles.css`
- **Mục tiêu:** Tạo 2 component modal popup chuẩn form Vira:
  - Form tạo dự án: Tên dự án, Mã Key (tự trích xuất chữ hoa), Loại dự án (Kanban/Scrum).
  - Form tạo workspace: Tên workspace.
- **Tiêu chí nghiệm thu:** Modal hiển thị trên overlay, có nút đóng `X` và nút hủy, validate input trước khi gửi, có trạng thái loading khi đang lưu.

### Task 2: Xây dựng `<WorkspaceSwitcher>` tại thanh Sidebar
- **Files:** `src/main.jsx`, `src/styles.css`
- **Mục tiêu:** Thay thế thẻ tĩnh `div.workspace` bằng component tương tác:
  - Hiển thị tên workspace và project hiện tại kèm icon mũi tên.
  - Khi click: mở dropdown menu hiển thị danh sách dự án và danh sách workspace (đánh dấu dự án/workspace đang active).
  - Có 2 nút hành động: `+ Tạo dự án mới...` và `+ Tạo không gian làm việc mới...`.
  - Tự động đóng menu khi click ra ngoài.
- **Tiêu chí nghiệm thu:** Click chuyển đổi dự án nạp đúng dữ liệu Board; click chuyển đổi workspace nạp đúng danh sách dự án của workspace đó; click mở modal tạo mới hoạt động trơn tru.

### Task 3: Nâng cấp `<Setup>` Onboarding Wizard với 3 Task mẫu
- **Files:** `src/main.jsx`
- **Mục tiêu:** Khi tài khoản mới đăng ký (`workspaces.length === 0`), hiển thị wizard 2 bước:
  - Bước 1: Nhập tên Workspace.
  - Bước 2: Nhập tên Dự án & Key.
  - Khi bấm Hoàn tất: Gọi API tạo Workspace ➔ Tạo Project ➔ Tự động tạo 3 task mẫu trực quan ➔ Đưa thẳng vào Bảng Kanban.
- **Tiêu chí nghiệm thu:** Người dùng mới vào thẳng bảng Kanban đã có sẵn 3 thẻ task để kéo thả trải nghiệm ngay.

### Task 4: Kiểm thử toàn diện & Xác thực
- **Mục tiêu:** Kiểm tra các luồng:
  - Đăng ký mới ➔ Onboarding Wizard ➔ Kanban Board có sẵn 3 task mẫu.
  - Đang ở trong Board ➔ Mở switcher ➔ Tạo dự án thứ 2 ➔ Chuyển qua lại giữa 2 dự án.
  - Mở switcher ➔ Tạo workspace thứ 2 ➔ Chuyển qua lại giữa 2 workspace.
  - Chạy `npm run build` không lỗi.

# 9. Edge Cases & Handling

| Tình huống | Cách xử lý | Task xử lý |
|---|---|---|
| Click ra ngoài dropdown khi đang mở | Lắng nghe sự kiện `mousedown` trên `document` để set `isOpen = false` | Task 2 |
| Tạo dự án với mã Key không hợp lệ | Kiểm tra regex và chặn submit, báo lỗi trực tiếp trên modal | Task 1 |
| Workspace mới được tạo chưa có dự án nào | Tự động mở tiếp modal tạo dự án đầu tiên của workspace đó | Task 2 |
| Người dùng ấn nút Back hoặc Escape | Hỗ trợ phím Escape để đóng modal | Task 1 |
